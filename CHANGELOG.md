# Changelog

## 0.6.0

- First public release with model-neutral setup documentation and prerequisite links.
- Explicit tested-version matrix and PS4/TV commissioning checklist.
- Architecture and Mermaid flowchart.
- Reproducible fictional English/Hebrew screenshots, without household data.

## 0.5.0

- Persistent manual block, immediate enforcement trigger and explicit release.
- Block control hidden when already restricted by schedule or quota.
- Manual-block status in countdown and suppression of reminders.

## 0.4.0

- Automatic user-locale display language with English fallback; no language switch.
- Generic announcement labels without personal speaker names.
- Extra-time controls shown only outside allowed hours or after quota exhaustion.

## 0.3.0

- RTL Hebrew and LTR English views with language navigation.
- Isolated time ranges and countdown numbers; translated settings, charts and help.

## 0.2.0

- Daily +15/+30 minute bonus buttons, expiring by local date without requiring a midnight reset trigger.
- HH:MM countdown and bonus-aware enforcement/reminders, respecting closing time.

## 0.1.0

- Hebrew Bubble dashboard with standalone settings pop-ups.
- Daily activity charts for the last 7 and 30 days.
- Schedule/quota enforcement and quiet-hour reminder Blueprints.
- Optional CEC adapter script Blueprint with explicit physical-verification limitations.
- Persistent settings package, renderer, examples, installation and GitHub guides.
