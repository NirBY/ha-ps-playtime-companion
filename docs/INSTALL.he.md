# התקנה ושימוש — PS4 Playtime Companion

לפני ההתקנה קראו את [התאימות והדרישות המקדימות](COMPATIBILITY.md) ואת [הסבר הטכנולוגיה ותרשים הזרימה](ARCHITECTURE.md). גרסה זו נבדקה עם Home Assistant Core 2026.9.4; יש לבדוק מצב מנוחה ו־CEC בחומרה שלכם לפני הפעלת האכיפה.

## כפתורי ייבוא ודוגמאות

[כל היכולות, כפתורי Import ודוגמאות שימוש](CAPABILITIES.md). כפתור כחול פותח ייבוא Blueprint ב־Home Assistant שלכם. לתצוגה ולחבילת ההגדרות יש כפתורי התקנה עם הוראות; הן אינן Blueprint.

## מה מתקינים?

לוח Bubble בעברית, גרף שבועי וחודשי, שדות הגדרות נוחים ו־Blueprints לאכיפה ולכריזה. לוח תצוגה אינו Blueprint של Home Assistant: הוא מגיע כקובץ תבנית עם כלי להתאמת שמות הישויות.

## 1. הכנות

1. גיבוי מלא של הגדרות Home Assistant.
2. התקנת Bubble Card בגרסה 3.2 ומעלה ו־card-mod וגם config-template-card דרך HACS. רענון הדפדפן לאחר ההתקנה.
3. מצאו את ישות זמינות ה־PS4 ב־Developer Tools → States. היא צריכה להציג `online` כשהקונסולה פעילה ו־`offline` כשהיא אינה זמינה. אל תניחו שהשם זהה בכל התקנה.
4. ודאו שאזור הזמן של HA נכון.
5. הכינו דרך בדוקה למצב מנוחה. אין בחבילה payload פעיל של `standby.bin` ואין צורך לחבר PS4 ל־PSN או לעדכן קושחה כדי להשתמש בלוח.

## 2. Helpers וחיישן זמן

בהתקנה קיימת עם helpers של PS4 וחיישן זמן יומי: השתמשו בהם ואל תעתיקו את החבילה שוב.

בהתקנה חדשה:

1. העתיקו `packages/ps4_playtime.yaml` לתיקיית `/config/packages/`.
2. החליפו בקובץ את `sensor.ps4_ftp_status` בשם החיישן שלכם.
3. הפעילו packages בתוך סעיף `homeassistant` הקיים ב־`configuration.yaml` (אל תיצרו סעיף כפול):

   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```

4. בצעו בדיקת תצורה ולאחר הצלחתה הפעילו מחדש את HA.
5. הפעילו **פעם אחת** את `script.ps4_initialize_defaults`. פעולה זו מגדירה את שעות ברירת המחדל, מכסות 2/5/5 שעות, חלון כריזה 12–18 ותזכורות 30/10/1. היא אינה מפעילה מכשיר או רמקול. הפעלה חוזרת מאפסת את ההעדפות שלכם.
6. ודאו שחיישן `sensor.ps4_play_time_today` קיים ושיחידתו שעות. בדקו שאין שם עם סיומת `_2`; אם יש, השתמשו בשם בפועל במיפוי וב־Blueprints.

השדות אינם כוללים `initial`, כדי שהשינויים שלכם יישמרו באתחול. עד לאתחול ברירות המחדל אין להפעיל אכיפה.

## 3. Blueprints

לחצו על כפתור Import המתאים ב[מדריך היכולות](CAPABILITIES.md), אשרו ייבוא וצרו אוטומציה או סקריפט. לחלופין העתיקו את תיקיות ה־Blueprints למסלולים המתאימים תחת `/config/blueprints/` ורעננו את הרשימה. בייבוא דרך URL הנתיב עשוי לכלול תיקיית מחבר; דוגמאות YAML דורשות התאמת `use_blueprint.path` לנתיב בפועל.

### מצב מנוחה

אפשר ליצור script מתוך `cec_rest.yaml`, לבחור חיישן זמינות וטלוויזיה ולקרוא לו `PS4 Rest Mode`. שמרו את שם הישות בפועל. אפשר גם להשתמש בסקריפט מצב מנוחה אחר שכבר נבדק אצלכם.

בדיקה מבוקרת: שמרו את המשחק, הפעילו את הסקריפט, ודאו פיזית נורה כתומה קבועה. העירו באמצעות שלט PS4 ובדקו ש־GoldHEN עדיין תקין. FTP שאינו זמין אינו הוכחה למצב מנוחה. טלוויזיות מסוימות עשויות להציג תמונות וציוד HDMI נוסף עלול להשפיע על CEC. אל תחליפו את הסקריפט בניתוק חשמל.

### אכיפת שעות ומכסה

צרו אוטומציה מתוך `enforce.yaml`. בחרו את חיישן הזמינות, את חיישן השעות ואת שדות ההגדרות. ב־Rest Mode action בחרו פעולה שקוראת לסקריפט שנבדק. מומלץ לקרוא לאוטומציה `PS4 Playtime Enforcement`, כדי ששם הישות יתאים לתבנית; בכל מקרה ודאו את השם בפועל.

האכיפה נבדקת כל דקה, לאחר חזרת הזמינות, בשעת הסיום ובחצות. היום נבחר לפי אזור הזמן של HA. שעת הסיום אינה כלולה בטווח המותר. ביום שישי ביטול שעת סיום תקף עד חצות; לאחר מכן כללי שבת חלים.

### תזכורות קוליות

צרו אוטומציה נוספת מתוך `reminders.yaml`. בחרו אותם חיישנים ושדות. ב־Announcement action בחרו `tts.speak`, ספק TTS ורמקול, ובשדה message הזינו `{{ message }}`. השפה תלויה בספק שלכם; `iw` היא דוגמה לספק Google בעברית, ולא ערך אוניברסלי.

החלון נבדק גם בתחילת האוטומציה וגם מיד לפני פעולת ההכרזה. אל תוסיפו delay לפעולת ההשמעה. אם משתמשים בסקריפט מאוחר או בתור השמעות, עליו לבדוק מחדש את חלון הכריזה ברגע ההשמעה. התראה שחלה בשעות שקט מדולגת. התחלת משחק אחרי נקודת ההתראה עלולה לדלג עליה.

## 4. לוח Bubble

1. העתיקו את `dashboard/entities.example.yaml` לקובץ מיפוי משלכם.
2. בצד ימין של כל שורה כתבו את שם הישות אצלכם. אם שיניתם גם שמות של helpers, הוסיפו שורות מיפוי עבורם. אין צורך לגעת בשמות שמופיעים משמאל.
3. הריצו מתיקיית המאגר:

   ```powershell
   python -m pip install -r requirements-dev.txt
   python tools/render_dashboard.py --mapping dashboard/entities.example.yaml --output dashboard/rendered.yaml
   ```

4. ב־Settings → Dashboards צרו לוח חדש עם URL path: `ps4-settings`.
5. פתחו את הלוח, Edit dashboard → Raw configuration editor והדביקו את תוכן `dashboard/rendered.yaml`.
6. שמרו ורעננו. לחיצה על קבוצת ימים פותחת חלון לעריכת שעות ומכסה. כפתור תצוגה חודשית פותח 30 ימים.

אם בחרתם כתובת אחרת ללוח, הוסיפו לכלי `--dashboard-path your-dashboard`.

## 5. שימוש יומיומי

- שעות ומכסות: לחצו א׳–ה׳ / שישי / שבת. מספר כמו 2.5 הוא שעתיים וחצי.
- שישי: כיבוי מתג שעת הסיום מאפשר משחק עד חצות בכפוף למכסה.
- כריזה: מתג נפרד והגדרות שעות שקט ותזכורות. ברירת המחדל היא 12:00–18:00 בכל יום.
- שינויים אינם דורשים אתחול; האכיפה הבאה בתוך כדקה. הקטנת המכסה או צמצום השעות בזמן משחק עשויים לסיים אותו.
- טווח חוצה חצות אינו נתמך. שעת סיום שאינה מאוחרת מההתחלה תציג אזהרה ותמנע אכיפה באותו פרופיל עד התיקון.

## 6. משמעות הגרפים

כל עמודה היא שעות פעילות ביום, לפי שינוי הסכום המצטבר בסטטיסטיקה ארוכת טווח. מכסת היום מתאפסת בחצות, אך ההיסטוריה נשמרת. זמן מסך הבית נספר; ניתוק FTP/רשת אינו נספר. הגרף אינו זיהוי מדויק של משחק פעיל.

יום ההתקנה עשוי להציג רק חלק מהיום, וימים ללא מידע אינם אפס שעות. הנתונים בגרף יכולים להתעדכן מאוחר יותר מהחיישן החי. אין יצירת היסטוריה מלאכותית לימים שלפני ההתקנה.

## 7. תקלות, עדכון וחזרה לאחור

- `Custom element doesn't exist`: ודאו ש־Bubble Card ו־card-mod מותקנים ומשאבי frontend נטענים, ואז רעננו.
- שדה חסר: ודאו שם ישות במיפוי ובכל Blueprint.
- אין גרף: בדקו שהחיישן כלול ב־recorder, ש־state_class הוא `total_increasing`, ושכבר נוצרה סטטיסטיקה. בדקו Developer Tools → Statistics.
- PS4 נשאר דלוק: בדקו את פעולת מצב המנוחה בנפרד, הגדרות HDMI Device Link ו־CEC. אל תסיקו מהטלוויזיה בלבד.
- כריזה מאוחרת: בדקו את השעה המקומית ואת פעולת ה־TTS המותאמת, כולל עיכובים/תורים.
- לפני עדכון: גיבוי קובצי הלוח וה־Blueprints. החליפו רק קבצים שנדרשים לעדכון, בדקו תצורה ובצעו Reload מתאים.
- לחזרה לאחור: השביתו את האוטומציות החדשות, החזירו את גיבוי הלוח/ה־Blueprints. אל תמחקו את חיישן הזמן או את הסטטיסטיקה אם רוצים לשמור היסטוריה.

## תוספת זמן ומונה

כפתורי +15 ו־+30 דקות מוסיפים למכסה של היום בלבד. התוספת אינה דוחה את שעת הסיום ופגה בחצות לפי תאריך מקומי, גם אם HA היה כבוי באותו רגע. המונה מציג שעות:דקות עד המוקדם בין סוף המכסה לשעת הסיום ומתעדכן בערך בכל דקה. כשהקונסולה אינה זמינה הוא מסומן כיתרה זמינה; מחוץ לשעות הוא מציג 00:00. ההתראות משתמשות במכסה הכוללת את התוספת, ועדיין כפופות לשעות השקט.

בשדרוג מהגרסה הקודמת: הוסיפו מהחבילה רק את `input_number.ps4_bonus_minutes`, את `input_datetime.ps4_bonus_date` ואת הסקריפט `ps4_add_playtime`, ועדכנו את שני ה־Blueprints ואת הלוח. אין צורך להפעיל שוב את סקריפט איפוס ברירות המחדל. ודאו שמזהי הישויות החדשות תואמים למיפוי. התוספת מוגבלת ל־600 דקות ביום ואינה עוברת ליום הבא.

## שפת התצוגה

השפה מזוהה אוטומטית לפי שפת פרופיל המשתמש ב־Home Assistant: עברית מוצגת RTL, וכל שפה אחרת או שפה לא מזוהה מוצגת באנגלית LTR. אין כפתור שפה. לאחר שינוי שפת הפרופיל יש לרענן את הלוח. האוטומציות אינן תלויות בשפת הצפייה; שפת הכריזה נשארת כפי שהוגדרה. כותרות ה־Blueprint עצמו באנגלית, שכן זהו מנגנון שרת ולא תצוגה של משתמש מסוים.

## מתי מופיעים כפתורי תוספת הזמן?

רק מחוץ לשעות המשחק או כשהמכסה היומית נוצלה, כולל התוספת שכבר ניתנה היום. בזמן מותר עם מכסה פנויה הכפתורים מוסתרים. טווח לא תקין מסתיר אותם עד לתיקון. התוספת עדיין אינה דוחה את שעת הסיום.

בשדרוג יש להוסיף גם את החיישן `binary_sensor.ps4_extra_time_available` מתוך סעיף `template` של החבילה ולעדכן את תבנית התצוגה. התקינו config-template-card בנוסף ל־Bubble Card ו־card-mod. החיישן קורא את השעות והמכסה בכל שינוי רלוונטי ובכל דקה, ומאפשר תצוגה זהה בכל המכשירים.

## חסימה ידנית

״חסום עכשיו״ מופיע רק כשאין חסימת שעות/מכסה ואין חסימה ידנית. הלחיצה מפעילה את אוטומציית האכיפה וקובעת חסימה ידנית, שמבקשת מצב מנוחה אם הקונסולה זמינה. ניסיון שימוש נוסף נאכף לאחר חזרת הזמינות. החסימה נשמרת גם בחצות ובאתחול, עד לחיצה על ״שחרר חסימה ידנית״. השחרור אינו מדליק את הקונסולה ואינו עוקף שעות או מכסה. התזכורות מדולגות בחסימה ידנית.

בשדרוג: הוסיפו את `input_boolean.ps4_manual_block` ואת הסקריפט `ps4_block_playtime` מהחבילה, ועדכנו את ה־Blueprints והלוח. אם יש לאוטומציית האכיפה שם אחר, התאימו גם את היעד בתוך סקריפט החסימה. אין להפעיל שוב את סקריפט ברירות המחדל.
