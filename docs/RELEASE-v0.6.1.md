# v0.6.1 — Import buttons and capability examples

This documentation update makes installation easier to discover and follow.

- Add official My Home Assistant Import Blueprint buttons for enforcement, spoken reminders and the optional CEC Rest Mode adapter.
- Add installation buttons and fictional examples for the Bubble dashboard, helpers, weekly/monthly charts, extra time, countdown, manual block and schedule settings.
- Explain which features require package/dashboard installation and how URL-imported Blueprint paths differ from manual installation paths.
- Update the Hebrew installation guide with import navigation.

No automation, dashboard runtime or device-control behaviour changes. Existing v0.6.0 installations do not need to re-import Blueprints or initialize helpers again for this documentation update.

Compatibility is unchanged: Home Assistant Core 2026.9.4 validated; Bubble Card 3.2+, card-mod and config-template-card required. Physical PS4/TV CEC commissioning remains necessary. No working standby.bin is included.

Validation: all eight portable configuration tests passed; all three import targets resolve to bundled Blueprint files. Examples and screenshots contain fictional data. The ZIP contains only version-controlled project files.
